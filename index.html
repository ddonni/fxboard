이 정보판에 대해

  • 추적 값 — 엔화/원(JPY→KRW) 환율, 100엔당 원화로 환산해 표시
  • 데이터 출처 — ExchangeRate-API (open.er-api.com) — 무료·무로그인, API 키 불필요. 링크를 열면 지금 이 페이지가 실제로 호출하는 것과 동일한 원문 응답을 바로 확인할 수 있습니다.
  • 수집 주기 — 매일 00:10(KST) GitHub Actions 스케줄 워크플로 자동 실행
  • 정직성 원칙 — 수집에 실패해도 이전 값을 조작하거나 감추지 않고, 실패 사실과 사유, 그리고 마지막 정상값을 그대로 보여줍니다
  • 개인정보 — 이 페이지와 수집 과정에는 로그인, 쿠키, 개인 식별 정보가 전혀 사용되지 않습니다
