과제 5 — 두 세션 인계 비교 보고서

"대화가 끊겨도 이어지는 프로젝트"의 검증 결과입니다. 과제 4(오늘의 진짜 정보판)에 "최근 7일 추이 스파크라인" 기능 하나를 두 개의 서로 다른 AI 세션이 차례로 이어받아 완성하게 하고, 두 번째 세션이 대화 전문 없이 저장소와 인수인계 문서만으로 같은 검사를 통과시키는지 시험했습니다.

이 페이지는 로그인 없이 누구나 볼 수 있습니다. 대화 전문은 포함하지 않으며, 고정 검사·집계 결과·인수인계 문서·판단만 남겼습니다.

개선 내용

fx-board(과제 4)의 "오늘" 카드에 저장된 daily_readings 중 최근 최대 7건을 이용해 상승·하락·횡보를 한눈에 보여주는 작은 SVG 선 그래프(스파크라인)를 추가했습니다. 기존 카드 1~5의 통과 기준은 하나도 깨지지 않았습니다(아래 검사 #8).

완주 체크리스트

  • ✅ 검사 10개와 공통 사용 상한을 구현 시작 전에 먼저 고정했습니다 — CHECKS.md는 첫 커밋(작업 시작 전 확정)에서 작성됐고, 이후 두 세션 모두 검사 정의를 바꾸지 않고 그대로 실행만 했습니다.
  • ✅ A 시작 → A 인계 → B 시작 → B 완료 순서가 커밋 이력으로 그대로 남아 있습니다 (아래 "커밋 순서" 참고).
  • ✅ 인수인계 7개 항목(목표/현재상태/남은작업/검사스냅샷/사용상한잔여량/파일지도/주의사항)을 담은 HANDOFF.md를 세션 1이 작성했고, 세션 2는 이 문서와 저장소만 받고 새 환경(별도 서브에이전트)에서 작업을 재현했습니다.
  • ✅ 세션 2는 대화 전문을 전달받지 않고, 저장소 경로와 "HANDOFF.md·CHECKS.md를 읽고 이어서 작업하라"는 지시만으로 같은 검사 10개를 실행했습니다.
  • ✅ 이름을 가린 측정표(아래 "고정 검사 10개 결과")와 도구 선택 기준(아래 해당 절)을 이 페이지에 남겼습니다.

도구 선택 기준

세션 1과 세션 2는 실제로 서로 다른 모델입니다 — 이름을 공개합니다.

  • 세션 1 = Claude Sonnet 5 (이 기획·설계를 이어온 메인 대화 세션). 이미 fx-board 전체 맥락(카드 1~5 구현 이력, 데이터 스키마, 통과 기준)을 갖고 있어 순수 로직 설계와 "일부러 미완성으로 남길 부분"을 결정하는 기획성 작업에 적합하다고 판단해 그대로 맡겼습니다.
  • 세션 2 = Claude Opus 5 (Agent 도구로 model: "opus"를 지정해 띄운 완전히 새로운 서브에이전트, 이전 대화 기억 없음). 일부러 더 높은 추론 능력이 필요한 DOM 통합·접근성·다크모드 대비·Playwright 브라우저 검증까지 맡겨서, "다른 LLM이 대화 없이 인수인계 문서만으로 실제로 이어받을 수 있는가"를 가장 엄격하게 시험하고자 했습니다.
  • 감사자 = 세션 1이 이어서 수행. 세션 2의 자체 보고를 그대로 신뢰하지 않고, 같은 검사를 저장소 상태만 보고 독립적으로 재실행했습니다(위 표의 "감사" 열).

짧은 확인 방법 (4줄)

위치
이 저장소를 배포한 fx-board 사이트의 "오늘" 카드 맨 아래 (메인 페이지).
3단계 이내 행동
① 메인 페이지 접속 → ② "오늘" 카드가 다 그려질 때까지 기다림 → ③ 카드 하단의 작은 선 그래프를 확인.
통과 모습
값/단위/출처/전일 대비 아래에 선 그래프(스파크라인)와 "최근 N일 추이: 최솟값 ~ 최댓값, 방향" 문구가 함께 보인다.
안 될 때 모습
그래프 없이 "최근 추이: 아직 정상 기록이 없어 그래프를 그릴 수 없습니다" 문구만 보이거나, 콘솔에 Sparkline is not defined 오류가 뜬다(스크립트 로드 실패).

AI와 나의 판단 (3줄)

AI에게 맡긴 일
검사 10개 정의, 스파크라인 순수 로직/DOM 통합 구현 전체, 인수인계 문서 작성, 두 세션 결과의 재실행·비교, 이 보고서 초안.
직접 판단한 일
개선 항목을 "스파크라인"으로 정한 것, 세션 2를 이 대화 안의 다른 모델 서브에이전트로 실현하기로 한 것, 감사 대상(외부 네트워크 상한 위반 여부)의 최종 결론을 검토·승인한 것.
AI 제안을 따르지 않은 일
세션 2가 표에 남긴 마크다운 서식(||)은 그대로 두지 않고 수정했고, "상한 위반일 수 있다"는 세션 2의 잠정 우려를 그대로 받아들이지 않고 감사를 거쳐 별도로 판단했다.

증거 보관 기준

이 페이지에는 두 세션의 대화 전문이 포함되어 있지 않습니다. 고정 검사(CHECKS.md), 집계 결과(위 표), 인수인계 문서(HANDOFF.md), 그리고 이 판단만 남겼습니다.
