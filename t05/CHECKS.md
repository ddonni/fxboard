# 과제 5 최종 실행 — 고정 검사 10개

AI A 시작 전에 고정했습니다. 실행기 `t05/run_checks.js`가 아래 입력·기대값을 그대로
구현합니다(대상 버전의 다른 테스트 파일을 믿지 않고 독립 구현).

- 실행: 저장소 루트에서 `node t05/run_checks.js` (작업 트리 검사, 결과를 `t05/runs.jsonl`에 추가)
- 특정 버전 검사: `node t05/run_checks.js --target <커밋>` (git worktree로 꺼내 검사, 기록 안 함)
- **고정 입력 데이터**: 화면 검사(DC-07~09)는 대상 버전의 `data/history.json`이 아니라
  **기준 버전(이 문서를 처음 추가한 커밋)의 `data/history.json`** 을 브라우저에 공급한다.
  실제 데이터 5건: 09-17 876.93 / 09-18 881.88 / 09-19 886.10 / 09-20 882.14 / 09-21 880.71.
- 기준 버전: `git log --diff-filter=A --format=%H -- t05/CHECKS.md`의 가장 오래된 커밋
  (태그 `t05f-baseline`).
